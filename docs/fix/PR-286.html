fix(hvac_log): 照片放大层默认隐藏，不再遮住整页

PR-286 · 更新: 2026-09-13T11:58:10-04:00

现象

重启 hvac-log 服务、第一次加载 0.8.0 前端后，整页被一层深色遮罩盖住，右上角有个 ✕，所有点击都没反应。

根因

0.8.0（182e0b8）给 .lightbox 写了 display: flex。作者样式表优先于浏览器给 [hidden] 的 display: none，所以 #lightbox 带着 hidden 属性照样显示，成了一层 position: fixed; inset: 0; z-index: 50 的 88% 深色遮罩。关闭函数只把 hidden 设成 true，而它本来就是 true，所以点 ✕、按 Esc 都没用。

style.css 里 .toast 早就处理过同一个问题（「display:flex 会盖掉 hidden 属性自带的 display:none」），.lightbox 漏了这一条。

改动

  • apps/hvac_log/static/style.css：加 .lightbox[hidden] { display: none; }
  • apps/hvac_log/tests/test_static_hidden.py（新增）：回归锁。不认具体元素——index.html 里带 hidden 属性的元素，只要它的 class 在 style.css 里有非 none 的 display，就必须有对应的 [hidden] 规则。

证据

  • 修前：新测试失败，只报 <div class="lightbox" hidden>：.lightbox 设了 display: flex，缺 .lightbox[hidden]
  • 修后：新测试通过；pytest apps/hvac_log/tests 全量 349 passed
  • 浏览器（线上 8655，未重启服务）：#lightbox hidden=true、computed display=none，页面中心最上层元素为日历格子，控制台无报错

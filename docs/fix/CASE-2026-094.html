dev-log-timestamp-fix — 发布说明

CASE-2026-094 · 更新: 2026-08-27T18:25:45-04:00

dev-log Pages 展示的 Case 更新时间此前依赖 Case Manager App"标记发布"点击那 一刻写入 release-notes.md frontmatter 的字段，但那一刻该文件常常还在特性 分支 worktree 里、主树还不存在，写入会静默失败——导致时间戳退化成仅日期、 同天发布的 Case 排序错误（CASE-2026-089/093 反复复现）。

这次改动让 .github/scripts/sync_fix_improve_log.py 自己从 git 提交历史里 解析时间戳：回放 release-notes.md 的完整历史，找到最近一次把 status 改成 released 的提交，取其提交时间。彻底解耦对 Case Manager 写入时机的依 赖，找不到时无缝回退到原有逻辑，不影响任何既有行为。

同时把两个相关 GitHub Actions workflow（sync-fix-improve-log.yml、 reconcile-dev-log-sync.yml）的 checkout 深度改为完整历史，否则 CI 里看不 到需要的提交。

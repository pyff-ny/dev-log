fix(health_panel): round sleep card's latest value to avoid float display artifacts

PR-231 · 更新: 2026-08-30T16:09:40-04:00

  • _metric_stats() rounded win7/win30/win90 mean/sd to 2 decimals but left latest.value as the raw float sum from _daily_sleep_total(), which can carry IEEE-754 artifacts (e.g. 4.7 + 2.6 → 7.300000000000001).
  • The frontend (app.js) renders latest.value directly as the big "小时" number on the 睡眠 overview card — this is what surfaced the bug (screenshot showed 7.3999999999999995).
  • Fix: round val to 2 decimals in _metric_stats(), matching the existing mean/sd precision. Affects sleep/steps/exercise latest.value uniformly (only sleep, being float-valued, was actually exhibiting the artifact).

# return-to-root-fix-2 — 发布说明

_更新: 2026-08-24_

第一增量（已发布，PR [#151](https://github.com/pyff-ny/toolbox/pull/151)）：
1. 页面顶部新增常驻位置行，随时显示当前 ROOT 与本轮回根是否已开始。
2. 「开始一次回根」点击后按钮文案与视觉状态明确改变，不再是无声操作。
3. 所有写入类操作的成功与失败提示改为出现在触发按钮紧邻位置，不再集中挤在页面最下方或只在「生根」页可见。

第二增量（已发布，PR [#153](https://github.com/pyff-ny/toolbox/pull/153)，merge commit `4ae0749`）：
4. 「建立支线」后自动进入该支线，可以立刻继续书写；DEVELOP/FEATURE 区域的写作现在真正落盘（此前完全没有接线，刷新即丢失）。
5. 面包屑显示 `ROOT → MAIN → 父支线 → 当前支线`，逐段可点击返回上一层/MAIN。
6. 顶层与每条支线各自拥有独立的写作历史（append-only），互不覆盖、互不污染。

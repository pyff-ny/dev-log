CASE-2026-089 · 更新: 2026-08-26T12:51:37-04:00

修复 dev-log 上部分已发布 case 的显示问题。根因：case-manager-app 的"标记发布"动作要给 release-notes.md 盖上 status: released + 精确时间戳，但只有在点击发布那一刻这份文件已经 存在时才会触发；文件内容如果是点击发布之后才补全的，这次盖章就不会发生。

排查后发现影响范围比最初以为的大：83 个已发布 case 里，74 个时间只显示到日期没有具体时间， 其中 46 个更严重——release-notes.md 自己的 status 字段根本没变成 released，这些条目很可能 从未在 dev-log 上出现过。

给 .github/scripts/sync_fix_improve_log.py 加了一个可复用的 --repair-release-metadata 模式， 从每个 case 自己的 case.md（App 维护、权威但不进 git）回填 release-notes.md 的 status 和 updated 字段，跑了一次修复全部 83 个 case（74 个实际有改动，9 个本来就对）。

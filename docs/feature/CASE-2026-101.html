两件事一起发：收《地藏经》，以及让一次阅读可以暂停后续读——后者是前者的可用性前提， 1.7 万字一遍读不完是常态。

新增《地藏菩萨本愿经》

底本是 Jia 提供的《地藏菩萨本愿经（简体校勘注音版）》（地藏七 编，2010 年版， 唐实叉难陀译）。经特征句核验，该底本属藏本系校勘版（含「生人天中受胜妙乐者」， 不含流通版的「是人眷属.如有福力」），与卷首印光大师序「宜以藏本为主」的主张一致。

- 13 品，69 段，16,929 汉字。只收正文（原书 p8–142），不收开经偈、补缺真言、 回向文、西方发愿文与校勘附录。 - 该底本以 . 作顿点，正文原样保留，不做标点校订——沿用 app 一贯的「原样录入」原则。 - 品次与品名是原书固有的；但原书正文连排、没有自然分段，所以 69 个段是按约 250 字 就近顿点切出的阅读与批注单位，两处偈颂整块成段并保留换行。它们不是原书分段， 更不是传统科判——README、模块 docstring、抽取脚本三处都写明了这一点。 - 正文由一次性抽取脚本从底本 PDF 生成，脚本随 Case 保存（30-implementation/extract_dizangjing.py）， 不进 app 目录。

阅读可以暂停、续读、留书签

会话由「开始 → 读完」两态扩为 running / paused / finished 三态：

- 点暂停：当前累计时长落库，同时记下读到哪一段。 - 回到这部经会看到一条恢复条幅（已累计多久、上次读到哪一品）， 三个出口：继续阅读 / 标记读完 / 放弃这次。 - 点继续阅读：自动滚回书签那一段并高亮，计时从累计值接着跑， 暂停期间的时间不计入。 - 跨天、关掉浏览器再开都能恢复——状态存在数据库里，不依赖页面存活。 - 切换到另一部经时自动暂停（不再像 v2.0.0 那样把会话废掉），回来还能接着读。 - 阅读期间每 60 秒向服务端报到一次；页面崩溃或断网时，服务端按最后一次报到截断， 离线的时间不会被算成在读（最多多算 90 秒）。

数据与接口

- sessions 加四列（accumulated_seconds / resumed_at / last_seen_ts / bookmark_section_id），只加列。既有 4 次阅读、18 条批注一条未动、统计一字未变。 - 新增 GET /api/session/open 与 POST /api/session/{pause,resume,heartbeat,discard}； POST /api/session/start 在该经已有未结束会话时返回 409。 - 既有端点行为全部不变；/api/badge 由 2 条变 3 条，字段名与数组形状不变， mk_hub 徽章总览无需改动。 - 一处经批准的语义变更：放弃的会话现在把已读时间计入累计阅读时长（仍不计完整次数）。 理由是这个 app 的立意是「诚实的痕迹」，那些时间确实读了。

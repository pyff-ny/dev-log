文字旁边终于有了实物凭据

job 表存着一次维修的全部文字：symptom → diagnosis → resolution → parts_replaced。这四句话是这套系统里信息密度最高的东西，也是明年面试要用的 话术底稿。但它们全是事后回忆写下的转述。

转述会褪色，也会在无意中被后来的理解改写。「压缩机接线盒 C 端烧黑」半年后再读， 烧成什么样已经想不起来了；「铭牌显示 R-404A，3.2 吨」——铭牌照片没留，型号反查 不回去。

0.8.0 给工单加照片。时间线页把一天的工单展开之后，每单下面是一排现场照片， 加一个「＋照片」按钮。点缩略图放大，放大层里按 Delete 删掉、Esc 关掉。 每张可以带一句说明、一个类型（症状 / 铭牌 / 拆解中 / 换下的件 / 完工 / 其他）， 以及可选的关联部件。

挂在 job 而不是 work_day。 一天跑三个活，一列「今天的照片」说不清是哪台 机器的哪个毛病。库里原有的 work_day.photo_path 是 0.1.0 留下的天级单列， 展示层九页从没读过，本版起标为 compatibility-only——不删，也不用。

库里只存路径，盘上只存原图

照片进 ~/toolbox-data/db/hvac-log/photos/，按 YYYY-MM/ 分目录，库里存的是 相对路径加 sha256。

BLOB 进库这条路走不通：写入前的自动备份是 shutil.copy2 整个库文件，库涨到几 GB 之后，日历上点一天开工要拷几 GB。存绝对路径则是把真相托付给一个随时会变的东西 ——照片一挪一删就断链。存相对路径，库搬家或换机器都不用改数据。

文件名嵌内容 hash 前 8 位，配上 UNIQUE(job_id, sha256)：同一张图重传同一个工单 直接把既有那行还回去，不写盘也不插行。不会再出现 IMG_4821 2.jpg。

上传不走 multipart

cgi 模块在 Python 3.13 被移除，本机 3.14 实测已经 import 不到。标准库里因此 没有现成的 multipart 解析器，而手写边界解析是这条路径上唯一真正容易出 bug 的 地方——多字节边界、CRLF、尾部 --，每一处写错都是静默地少几个字节。

改发 JSON + base64，两者都还在标准库里。代价是传输体积涨 4/3，在 15 MB 上限和 本机传输下无所谓。

类型只认文件开头那几个字节。 前端声称的 mime 和文件名后缀一律不作数—— 浏览器给的 File.type 本来就时常为空。HEIC 因此拦得住，并且给的是一句照着做得了 的话：把相机设成「兼容性最高」，或者导出时选 JPEG。不转码：要么上 Pillow， 要么 subprocess 调 sips，两条都配不上「改一个相机设置」这个代价。

落盘顺序本身是契约

`` 写 .tmp/ → fsync → INSERT → COMMIT → os.replace 到最终路径 ``

先落库再改名，不是反过来。两种不一致的代价完全不对称：库里有行而盘上没图， 界面上那张图裂开，看得见也补得回来；盘上有图而库里没行，没有任何界面会显示它， 永远不会有人发现。

删照片是软删，文件移进 photos/.trash/，那个目录不自动清理——误删一张现场照， 重拍是不可能的。

顺带补上一把从来没写过的锁

README 从 0.3.0 起就写着「analyze.py hours --json 和网页工时页永远给出同一个数 ——test_serve.py 锁住这条」。那把锁其实不存在。 既有测试只断言响应形状 （状态码、query 名、rows 是不是 list），test_serve.py 文件头自己还写着 「不重复锁数值」，全仓没有任何一处把 CLI 的字节和 HTTP 的字节比过。

架构上一致性是真的（两边共走 run_query 唯一入口），但架构保证不了未来。 本版把 timeline 和七个不依赖参考日的查询都焊死。

两次被自己的评审打回

第一轮 DO NOT MERGE：字段白名单收下了 filename 和 mime，而写函数一次都没读 过它们，前端却每次都在发。收下再忽略等于静默丢弃调用方给的东西——这正是这套系统 在《字段归属》里写明、并且 0.4.0 专门为它改过 import.py 的规矩的反面。

第二轮 BLOCKED：上一轮的修复让两条测试的 400 改从白名单来，它们仍然绿着， 却不再守着各自那条路径。修的过程中又抓到第三条同族假通过——那条与本次改动无关， 是一开始就写错的。

据此定下规矩：每一条断言 400 的用例，都必须同时断言错误信息来自它想测的那道闸。 只断言状态码，等于把「这条路径还有人守着」托付给闸门的相对顺序，而顺序是会变的， 变了也不会有人收到通知。

测试从 272 涨到 348（pytest），12 涨到 40（node）。

CASE-2026-008 · 更新: 2026-08-10

case-manager-app v1.1.0：

  • 新增 Inbox：想法先进 Inbox（new → cooling → reviewing → promoted | archived），有潜力再一键升格为正式 Case 并自动预填需求文档「问题」小节（带 > 来自 INBOX-... 溯源），减少不成熟想法直接变成正式 Case。
  • 前提改动：cases/、goals/ 从工作区根目录迁移到 case-manager-app/ 下，Inbox 与其同级存放；--cases 默认值同步更新，goals_root 自动跟随。
  • 顶部标签栏改为 Inbox / Case / Goal / 日志 / 说明 / 笔记，Inbox 排首位并为默认标签。
  • Case 列表左侧排序调整：组间与未分组 Case 改为按 case number 降序（原按组内最新 updated 时间排序），组内 sequence 顺序不变。
  • 7 个新 API 端点：GET/POST /api/inbox、GET /api/inbox/<id>、GET/PUT /api/inbox-documents/<id>/idea.md、POST /api/inbox/<id>/status、POST /api/inbox/<id>/promote。

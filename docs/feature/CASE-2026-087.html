case-manager-close-function — 发布说明

CASE-2026-087 · 更新: 2026-08-26T03:20:36-04:00

Case Manager 新增"作废 Case"功能：处于 intake/design/plan/implementation/review 任一阶段的 case，可以标记为 abandoned——一个独立于既有 release → archive 归档路径的终止状态，参照 Inbox 的 archived 模式设计。作废需要填写原因，写入一条新的签名 timeline 事件（lifecycle.abandoned），案子从活跃列表移出但保留全部历史，可在新增的"已作废"面板里查看。

背景：像 CASE-2026-039 这类在 intake 阶段就判定不再推进的 case，此前无处安放，只能悬空留在活跃列表里。

hvac-log-app — 发布说明

CASE-2026-102 · 更新: 2026-09-06T00:53:51-04:00

新应用 apps/hvac_log/。把每天跟师傅出工学到的东西结构化存下来，可回溯、可复盘、可统计。

本次只交付 P0 建库 + P1 导入，分析层与展示层另开 Case。

数据库

18 张表 + FTS5 全文索引 + 6 个触发器，落在 ~/toolbox-data/db/hvac-log/hvac-log.db。

`` 字典层 level_scale · skill_grade_scale 学习域 job · learning · safety_observation · question · learning_gap 部件域 component_type · component_install 设备域 equipment 工作域 work_day · work_segment · session 技能域 skill · skill_observation 收入域 comp_period · market_rate · min_wage ``

系统最重要的不变量：知识条目按来源分级，并支持「待核实 / 已证伪」状态。 verified = 2 的条目保留原文，在 verify_note 里写正确说法，不删除—— 这样能回顾自己纠正过哪些误解，也能看出师傅哪些说法不可靠。

三条原本只写在文档里的规则，这次下沉成了数据库约束：

  • 自评不能单独把技能推到 L3 → CHECK (NOT (source='self' AND level>=3))
  • job.status 是状态机不是标签 → job_status_fsm 触发器强制迁移
  • 工时区间不许重叠 → seg_no_overlap_ins/upd + CHECK(work_date=substr(start_ts,1,10))

导入

import.py：JSON Schema 校验 → 语义检查 → 预览 → 确认 → 备份 → 单事务写入。 以「日」为单位，重复导入同一天替换那天的记录，天然幂等； component_type / equipment / skill 是累积知识，只 upsert 永不删除。

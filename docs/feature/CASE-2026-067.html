更新: 2026-08-22

FrameNote v1.0.0 初版：

  • 本地 SMB 影片库的 YouTube 式播放工作区。
  • 视频与时间轴文字的双向关联：输入自动暂停，保存自动播放，点击时间返回画面。
  • 影片/导演/类型/个人主题/评论统一搜索。
  • OMDb 人工确认元数据并复用现有 media.db.movie_meta。
  • MKV/RMVB 按需 ffmpeg 转码到 _web_playable。
  • mk serve lifecycle 增加 bounded readiness、health/stale 检查和 legacy fallback。
  • 首版 snapshot：apps/frame_note/releases/v1.0.0/。

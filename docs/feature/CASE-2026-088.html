note-vault — 发布说明

CASE-2026-088 · 更新: 2026-08-26T12:03:15-04:00

新增独立的 mk serve app note_vault v0.1.0：一个与 UIW / Case Manager 零耦合的个人文本捕获、 自由标签与全文检索工具。核心能力：

  • 顶部常驻粘贴框，Cmd/Ctrl+Enter 一键保存，标题不填时自动取内容首行
  • 自由标签，录入时可选、事后随时补/改
  • SQLite FTS5 全文检索，支持中文内容匹配
  • 按标签筛选 + 关键词搜索，可叠加
  • 条目原地展开，支持编辑（modal）和软删除/恢复

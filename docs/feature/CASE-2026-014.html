Git Handoff for Approved Cases — 发布说明

CASE-2026-014 · 更新: 2026-08-19

Case 进入 release 阶段（评审已过、等待/记录发布交付）后，Case 详情页新增 "Git Handoff" 面板：

1. 只读展示建议的分支名（claude/<slug(标题)>-<确定性 6 位哈希>）与仓库 URL（从本地 git remote get-url origin 只读探测），并列出依赖阻塞项中尚未发布的风险提示。 2. Jia 点击"确认 Git handoff"后，记录一条可审计的 timeline 事件（不改 case.md），随后展示回填表单。 3. Jia 手动创建分支/PR/merge 后，回到面板填写仓库、分支、PR 编号、PR 链接、merge commit，提交后写入 case.md 正文"当前状态"小节与 changelog.md，作为交付证据留痕。

不做：不自动 push、不自动开 PR、不根据评分或任何自动化触发 Git 操作——分支创建、commit、push、PR 全部由 Jia 手动完成。

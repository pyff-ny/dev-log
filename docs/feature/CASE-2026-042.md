# Inbox 归档/删除按钮

_更新: 2026-08-14_

版本 `v2.2.2.3`。Inbox tab 新增两个按钮：

- **归档**：`reviewing` 状态条目可见，点击后调用既有的 `saveIdeaReview("archived")` 路径（`POST /api/inbox/<id>/idea-review`，`conclusion: "archived"`），与 Idea Review tab 的归档效果完全一致。后端零改动。
- **删除**：`archived` 状态条目可见，点击后二次确认，调用新增的 `DELETE /api/inbox/<id>` 端点。服务端二次校验 `status == "archived"`，通过后永久删除整个条目目录（无回收站）。

调查确认用户最初报告的"重复 item"（`INBOX-2026-003`/`INBOX-2026-007` 标题相同）不是数据 bug，而是两条独立创建的真实条目；本次功能就是清理这类重复的工具。

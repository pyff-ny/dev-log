mk-library-tracker — 发布说明

CASE-2026-093 · 更新: 2026-08-27

新增 mk serve 本地小工具 library_tracker v2.0.0：

- 手动记录借阅（书名/分类/借出日期/应还日期），当前借阅按应还日期临近/逾期 程度分色提醒 - 借阅历史（还过的书自动归档，可按分类查看）+ 分类统计 - 接入 mk_hub 现有 /api/badge 机制：有书临近应还（≤3 天）或逾期时才在 hub 面板出现提醒，平时安静无提示 - apps/mk_hub/serve.py 的 BADGE_APP_NAMES 追加 "library_tracker"

原计划是自动登录 Queens Public Library 官网抓取借阅记录，Stage 3 真实验证 时被官网 WAF 拦截、无法绕过，改为手动记录方案（详见 Case 的 10-design/decisions.md ADR-0004）。

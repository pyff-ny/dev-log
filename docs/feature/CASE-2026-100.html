jingangjing-扩展 — 发布说明

CASE-2026-100 · 更新: 2026-09-03T01:38:06-04:00

jingangjing 由「金刚经读诵记数」扩展为集成的佛经诵读 app。

新增《心经》

玄奘译通行本，按意群分 7 段（观照总纲 / 色空不二 / 诸法空相 / 空中无相 / 无明与四谛 / 菩萨与三世诸佛 / 般若咒）。段标题是为逐段批注而定的阅读单位标签，不是传统科判—— 心经没有传统分品。与金刚经享有完全同等的待遇：独立计时、独立完整次数、逐段批注、独立历史。

界面改为总览侧栏

左栏是置顶「总览」+ 已收录经文列表，每部经显示「完整次数 · 距上次读完多少天」； 右区随选中项整体切换。跨经的汇总统计、各经一览、最近 10 次会话只在「总览」出现一次， 不在每部经的页面里重复。选中某部经时，阅读 / 历史 / 批注总览三页全部限定在这部经内。 窄屏（≤900px）侧栏塌成顶部横条，所有经文一屏可见。

计时途中切换到另一部经会先确认；确认后这次会话留作「未完成」，与关掉页面同义。

正文来源改为 scriptures/ 包

sutra_content.py（单文件、扁平 SECTIONS）改为 scriptures/ 包：注册表 __init__.py + 每经一个只读内容模块。收录一部新经＝新增一个文件 + 注册表加一行， serve.py 一行不动——地藏经将来直接沿此路进来。金刚经 32 分正文逐字迁入，未动一字 （sha256 前后一致，且有测试常驻锁住）。

数据与接口

- sessions / notes 各加 scripture 列（只加列，additive）。既有 3 次完整阅读与 18 条理解笔记由 DEFAULT 'jingangjing' 回填为金刚经，一条未丢、统计一字未变。 - 新增 GET /api/scriptures；/api/sections、/api/sessions、/api/stats、/api/notes 接受 ?scripture=；POST /api/session/start、POST /api/notes 接受 body 里的 scripture。不带新参数时行为与 v1 完全一致。 - /api/badge 由 1 条改为每经一条（key=last_read_<slug>，label 带经名）， 数组形状与四个字段名不变。mk_hub 徽章总览无需改动即可显示；当天已读完的经会被 mk_hub 既有的过滤规则自动隐去，不占面板位置。

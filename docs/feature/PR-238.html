feat(john_wick_arsenal): 新增查价来源链接字段 v0.3.0

PR-238 · 更新: 2026-08-31T10:46:42-04:00

接 #237（价格字段 v0.2.0）。新增第三个可选字段 price_source_url，把「这个价是从哪查的」一并存下来。

字段

``yaml price_usd: 4500.50 # 选填 price_checked_at: 2026-08-31 # 选填，与上面成对 price_source_url: https://… # 选填，有它就必须有上面两个 ``

依赖是单向的：有 URL 就必须有价格与日期（孤立的商品链接没有信息量），反过来不强制——价格可以来自链接之外的渠道。

校验

  • 必须以 https:// 开头；http://、纯文本店名、含空格的值一律报错
  • 沿用「不做猜测」的一贯做法，不清洗输入
  • 失败照旧三处暴露：启动日志 / /api/meta.failures / 前端告警条

URL 里的冒号不影响解析——frontmatter 解析器只在第一个冒号切分，https://example.com:8443/shop?sku=1&ref=a:b 有测试覆盖。

展示

只在详情面板，卡片上不放链接（太吵）。渲染为可点链接，文字取域名（去 www.），完整 URL 挂 title：

`` 参考价 $4,500.50（2026-08-31 查） 价格来源 xtremegunsandammo.com ``

链接带 target="_blank" + rel="noopener noreferrer" + referrerpolicy="no-referrer"。

关于「页面不得引用外部域」这条约束：那条针对的是页面主动加载外部资源（src / fetch / 外链 CSS）。<a href> 在用户点击之前不发任何请求，性质不同；加上 no-referrer 后点击也不向商家泄露来源页。

验收

47 个单元测试全绿（新增 7 条），/usr/bin/python3 3.9.6 下限跑。

scope 说明

计划声明 5 个文件，实际 6 个。多出的 style.css 加了 2 行——链接主题色与键盘焦点环，否则是浏览器默认蓝紫色且无焦点环，违反 UI Spec §1.5.6「全部交互元素可用键盘到达」。已向 Jia 说明并获认可。

已知限制

商品页 URL 寿命很短（下架、改版、SKU 变更），一两年内大概率 404。price_checked_at 因此同时是价格与链接的时效标记。程序不做链接存活检查——那需要外部网络请求，与本 App 的零依赖只读定位冲突。

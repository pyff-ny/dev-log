idea-review-tab — 发布说明

CASE-2026-009 · 更新: 2026-08-10

case-manager-app：

  • 新增 Idea Review：Inbox 里 reviewing 状态的想法现在有真正的评审工作流——8 项结构化 checklist（不打分）+ 独立的 idea_review_conclusion 字段（archived/candidate/promoted），分别复用既有 reviewing→archived、reviewing→cooling、mark_promoted 转移，不新增状态、不改状态机。新增「Idea Review」Tab 汇总所有待评审条目。
  • 新增「保存」按钮：checklist 可以先存草稿（不选结论、不改状态），不必一次填完。
  • Idea Review 的 checklist 答案在升格为 Case 时会预填进新 Case 的 00-intake/requirements.md，作为立项依据留存，不会因为 Inbox 条目变成 promoted 历史记录而丢失。
  • 升格对话框新增 Goal 选择（此前一直硬编码落到 GOAL-case-manager），默认选中 GOAL-capability-registry。
  • Inbox 详情页精简：归档/升格为 Case 从 Inbox 详情页拿掉，只保留 进入 cooling/进入 reviewing，避免和 Idea Review 的功能重复；reviewing 状态改为提示去 Idea Review 完成评审。
  • 顶部标签栏顺序调整为 Goal → Inbox → Idea Review → Case → 日志 → 说明 → 笔记。
  • 修正 GOAL-goal-capability-registry 重复前缀 bug（应为 GOAL-capability-registry）。
  • 新增 API：POST /api/inbox/<id>/idea-review。

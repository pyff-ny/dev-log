更新: 2026-08-09

给 Case Manager 加了顶级 tab 导航：📁 Case（原有功能，行为不变）、🎯 Goal（新建+查看）、📜 日志、📖 说明、📓 笔记。

  • Goal：新建只填标题，goal_id 自动从标题派生（冲突自动加数字后缀），不再需要手填 ID——CASE-2026-006 那次"手填 goal_id 打字错误导致侧边栏全部 Case 消失"的问题从入口上被消掉了。Goal 详情显示它的 Case 链（按 sequence 排序）和 goal.md 原文。
  • 日志：直接在 App 里看 case_manager 自己的运行日志（真实路径 ~/toolbox-data/mk_out/serve/case_manager.log，不是新建的日志），支持关键词过滤和可选自动刷新，ACTION: 操作记录会高亮。
  • 说明：App 内直接看 README.md，标题层级会渲染成真正的标题，顶部有"在 VS Code 中打开"的深链接。
  • 笔记：观察笔记存到 Obsidian（/Users/jiali/Obsidian/projects/case_manager/30_notes/），折叠式列表、点开看正文、支持删除（删除前会弹确认）。

不改变任何现有 /api/cases、/api/documents/*、GET /api/goals 的行为；新增的 5 组接口都是纯增量。

跨 Case 依赖关系字段 — 发布说明

更新: 2026-08-17

Case Manager 的 case.md 新增可选 frontmatter 字段 blocked_by_case_ids（逗号分隔的 Case ID 列表，如 CASE-2026-012,CASE-2026-013），用来单向声明"这个 Case 要等哪些 Case 先完成"。这条依赖关系只是可见提示，不做强制阻断、不做自动状态联动、不做循环依赖检测：

  • Case 详情页在有依赖未完成时显示 ⛔ 依赖未完成 badge，鼠标悬停能看到具体是哪些 Case 还没完成。
  • Goal 视图的"Case 链"列表里，每个 Case 卡片也会在优先级旗标旁边显示同样的 badge。
  • 一个 Case 被视为"已完成"，等价于它已经 archive，或者已经进入 release 阶段且 status 是 released；引用了不存在的 Case ID 一律按"未完成"处理。

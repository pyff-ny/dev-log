CASE-2026-049 · 更新: 2026-08-17T02:37:07-04:00

mk troubleshooting app（~/toolbox-data/mk_troubleshooting）新增「🔗 关联」：跨源 （TR 正式库、隔离区、Case Manager 沉淀草稿、Obsidian projects）发现语义相关的条目 并并置呈现，目标是减少知识碎片化、让相关笔记互相被看见。

不搬迁、不合并任何现有数据 store；关联缓存是纯派生物，删除后重新同步即可重建，不 损失任何事实。

架构：数据只读（TR/隔离/沉淀/Obsidian）→ 分析层在 iMac 上用独立 venv（bge-large-zh-v1.5） 离线计算 → 显示层（本 app）零依赖只读缓存。MacBook 上运行的 serve.py 全程不 import torch/sentence-transformers/numpy，不发起任何网络请求。

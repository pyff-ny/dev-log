case-manager-不同goal-id分组 — 发布说明

更新: 2026-08-09

Case Manager 侧边栏的 Case 列表从扁平列表改为按 goal_id 分组： - 同一 Goal 下的连续 Case 聚在一起，按 sequence 排序，组标题显示 Goal 标题 + Case 数 - 每个 Goal 的分组标题带一个哈希取色的色点，跨刷新颜色稳定 - 分组可折叠，折叠状态存 localStorage（key 为 goal_id），默认展开 - 没有 goal_id 或匹配不到 Goal 的 Case 归入固定的"未关联 Goal"分组，排在最后 - 搜索/直接选中折叠分组内的 Case 时，该分组自动展开

不改变数据 schema、后端 API、CLI 或退出码；纯前端展示层改动（C1）。

# 清理历史与仓库维护 Tab

_更新: 2026-08-16_

Case Manager 新增「历史 / 清理」Tab：追踪 Case 关联的本地 branch、worktree、tag 和 commit，在发布证据、人工审核和二次确认全部通过后，才允许清理本地资源，并把命令、exit code 和结果追加写入 Case 自己的 `60-cleanup/cleanup-history.jsonl`。

安全边界：写命令仅固定 argv allowlist（`git worktree remove <validated-path>`、`git branch -d <validated-branch>`）；不删除 tag、protected branch 或任何远端对象；无 shell 字符串拼接；`git branch -D`、`worktree remove --force`、`reset --hard`、`clean -fdx`、`update-ref -d`、`prune` 永久禁止。

不新增数据库，不新增外部依赖，不改动既有接口与 JSON schema。

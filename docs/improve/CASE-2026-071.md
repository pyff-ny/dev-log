# frame-note-improve-3 — 发布说明

_更新: 2026-08-23_

FrameNote（`apps/frame_note`，仍为 v1.7.0，本 Case 未改动 `VERSION`）。

1. **修复"刷新索引"两处根因**：
   - 删除原片后索引不清理：`/api/index/refresh` 新增可选 `apply_prune`（默认关闭，旧行为不变），apply 前先做安全范围校验（frame_note 自己的 `video_root` 只读扫描 vs `mk` 全局 dry-run 计数一致才允许清理），再对 `media.db` 做只读快照备份，最后调用既有的 `mk media db prune-missing --apply`。
   - 刷新按钮本身此前一直静默失败：`mk media db refresh` 缺少非交互执行必需的 `--real`，导致 `exit_code=1`；已修复并加回归测试锁定。
2. **新增"获取 IMDb 信息"按钮**：接线此前已存在但从未在前端调用的 `/api/omdb/search`、`/api/omdb/confirm` 后端接口，无新增外部依赖。
